How it works

It reads what your agent did

Artifacts looks through each conversation for signs that a file was involved. Pick an event to see what it finds.

Install

Features

Small app, useful details

🔍

Finds files for you

Uploads, file-editor creates and edits, shell redirections, archives, downloads, screenshots and paths named by the agent.

🎛

Filter and group

Search by name, path or conversation, filter by how the file appeared, or group everything by conversation.

📥

Download and preview

Pull any file that still exists out of the sandbox. Text opens as plain text, never as a web page.

📦

Container-only warning

See which files live only inside the sandbox, so you can save them before it is cleaned up.

⚡

Fast rescans

Remembers what it already read and only fetches new events. Refreshes every minute while the tab is visible.

🧩

Nothing else to run

It is an Agent Canvas App: one JavaScript file, no helper server, no launcher.

⚠ Only enable apps you trust

An enabled Agent Canvas App runs JavaScript inside Canvas and can make authenticated requests to your Agent Server. Artifacts is a single readable file: review the source before you enable it. It only reads conversation events and files, and uninstalling it removes just the app.

FAQ

Good questions

Does it change or delete my files?

No. It reads conversation history and file contents through your Agent Server and shows them. Uninstalling removes only the app itself.

Where does it run?

In your browser, inside Agent Canvas, as an OpenHands App. There is no separate server or launcher to start.

Can it open a file in my computer’s file manager?

No. A browser app cannot reach your computer’s file system, so it offers download and in-browser preview instead. An older standalone helper from the same project could open Explorer, but it is a separate tool.

What about very large files?

Files are read from the sandbox in 384 KB pieces and reassembled in your browser. Very large files have not been tested yet.

Does it work with cloud backends?

Agent Canvas Apps currently run against local backends, so Artifacts does too.

How do I update it?

The Apps screen has no refresh button yet. Uninstall Artifacts and add it again with the same source.

What is the license?

MIT. Use it, change it and share it.
